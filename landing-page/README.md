# AEGIS Official Landing Page

Built with Next.js 16 (App Router), Tailwind CSS v4, and Lucide Icons. Designed for ultra-fast deployment on **Vercel**.

## Local Development

1. Install dependencies:
```bash
npm install
```

2. Run the development server:
```bash
npm run dev
```

Open `http://localhost:3000` to preview the landing page.

## Deploying to Vercel

1. Import this repository into your [Vercel Dashboard](https://vercel.com/new).
2. Set the **Root Directory** to `landing-page`.
3. Click **Deploy**. Vercel will automatically build and host the landing page for free.
